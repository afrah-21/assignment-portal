Assignment Submission Portal

GitHub Pages Deployment Demo

Flask Application

Assignment submission with field validation and local JSON storage.

Automated Testing

Three pytest tests for valid submissions, missing registration numbers and invalid URLs.

Continuous Integration

GitHub Actions automatically tests every push.

Automated Reporting

Test reports are sent to a local receiver and delivered by email.

This is the static deployment demonstration. The working submission form runs in the Flask app.
